# dsh-foxbell-pet

[中文](README.md) · [English](README.en.md)

DeepSeek Harness（DSH）Web 网页右下角可拖拽的 **Foxbell 小狐狸桌宠**：多项目状态监控 + 完成语音提醒 + 🦊显隐开关。素材随包自带：**一键安装即用，无需手动放素材**。

![Foxbell](reference/桃子衣服粉狐狸形象.png)

## 功能

- **多项目状态监控** —— 桌宠头顶为每个"活跃项目"显示一张状态卡片，带状态灯：
  - 🟢 `running` 正在运行
  - 🟡 `approval` 有待批准
  - 🔴 `error` 本轮报错 / 断联
  - 🔵 `done` 已完成未读
- **点卡片切换会话** —— 点击项目卡片直接切到该项目会话（左侧栏 + 中间区，`sessions.open`）并标记已读；红灯/已完成卡片**点进去即消失**，再次报错会重新亮红。
- **完成语音提醒** —— 任意项目完成时随机播 `voice/done/*.m4a` + 蓝灯动作（默认高兴跳跃）+ 字幕（字幕与语音时长对齐）。
- **语音交互** —— 单击形象：只挥手（不出声）；双击形象：说话 + 「双击动作」（默认挥手）；点项目卡片：只切换（不出声）。
- **状态驱动动画**（Codex V2 图集 11 行全用）—— 动画随交互与任务状态变化：
  - 拖动方向：左拖**向左跑**、右拖**向右跑**、上拖**跳跃**；
  - 任务状态：任一项目**报错**→红灯动作、**完成**→蓝灯动作、**待批准**→黄灯动作、**完成未读**→审查姿态、当前会话运行→工作姿态；
  - 空闲时**东张西望**（look 行 9→10 连续 16 帧从左到右播一圈）。
- **🦊 显隐开关** —— 侧栏底部设置图标旁的开关（类似 Codex 的宠物开关），状态存 `localStorage`。
- **卡片等宽** —— 项目气泡为多行卡片（加粗标题 + 状态点，第二、三行显示最新运行状态），横向等宽对齐。
- **右键菜单**（v1.3.0）—— 右键桌宠弹出菜单：🔊声音（开=有声）/ 💬语音字幕 / 🧲落地物理 开关，🖱️双击 / 🟡黄灯 / 🔴红灯 / 🔵蓝灯 四场景动作绑定（**6 种动作可选**：跳/挥手/委屈/等待/审查/工作），以及「🦊隐藏桌宠」「ℹ️关于」。
- **动作子菜单实时预览**（v1.3.0）—— 进入动作子页，桌宠本体循环播放当前选中动作；点选其它动作即时预览切换；「← 返回」回主菜单后停止。
- **拖拽物理手感**（v1.3.0）—— 松手**重力坠落**、水平**抛掷惯性**、落地**压扁回弹**（可关；压扁落定后补一段跳跃）。
- **位置记忆**（v1.3.0）—— 拖拽/坠落停在哪个位置，刷新后停在上次落点（localStorage，右缘 24px 边距内自动夹紧）。
- **设置卡片**（v1.3.0，dsh rc.7+）—— 设置页插件配置区，与右键菜单读写**同一份配置**（本地 `localStorage` + settings scope 双后端，Host 持久化到 `~/.dsh/settings.yaml`）。

## 效率看板（v1.4.0）

五个组件 + 两个小增强：宿主聚合、随状态快照下发，**零新增常驻 UI**（迷你条仅悬停期间存在）；token 一律**纯 token 口径，不折算金额**。

1. **节奏档位**（时长姿态引擎）—— 宠物姿态随事件节奏自动变档：活跃 / **长跑看表**（turn 开着静默 ≥3 分钟，防挂机干等）/ 高强度 / **摸鱼抑制环视**（turn 关着静默 ≥15 分钟起四阶渐进）。换动画变体、**不变速**，档位跃迁只播一次短动画，新事件立即复位。
2. **Token 计量器** —— 一个计数器、三个表现面：
   - **悬停迷你条**：悬停宠物 ≈0.5s 浮现——节奏表盘（当前档位读数）+「今日 × · 本会话 ×」+「N 等审批 / N 运行 / N 完成」；**纯只读**，移开即消失（右键「🏷 今日用量」可手动唤出，点外部 / ESC 关）；
   - **日阈值举牌**：`dayLimitTokens` 达 80% / 100% 时宠物举牌「今日已消耗 X」，各报一次不轰炸；
   - **里程碑播报**：累计 token 过整数关口（默认 100 万，`milestoneUnit` 可调）气泡一句话。
3. **审批召集链** —— 审批等待 ≥5 分钟（`approvalFlickerMin` 可配）**且页面不可见**时，标签页标题轮换「🦊 审批等待中…」，批准或回到页面即恢复；右键「🗂 会话一览」列出全部会话（状态色点 + 点击直达）。
4. **小黑板** —— 任务完成后宠物旁限时出现「📖 总结」入口（默认 15s）→ 点开浮现本次总结浮窗（会话 / turn / token 三分账 / 工具调用 Top3（次数+耗时）/ 最长 turn / 报错数），停留 15s 自动消失，✕ / 点外部 / ESC 均可关；隐藏桌宠时直接分发一次（farewell 黑板）；右键「📊 查看最近总结」随时唤回。
5. **表达容器** —— 内容按形态分流：短数字 → **举牌**、一句话 → 气泡、明细 → 黑板浮窗；警报语音三优先级（语音组音频 > TTS 朗读 > 静默，`ttsEnabled`）。

两个小增强：**卡片行尾年龄标注**——动态行尾灰色「×s/×m」，分清"刚发生"还是"已挂 5 分钟"；**审批直达**——点状态卡即**智能跳转**：有待审批直达审批锚点，否则跳会话+标已读。

以上共 **12 项新配置**（`paceEnabled` / `paceIntenseEvents` / `paceLongrunMin` / `paceLoafStartMin` / `usageEnabled` / `dayLimitTokens` / `milestoneUnit` / `approvalFlickerMin` / `summaryEnabled` / `summaryEntrySec` / `boardTtlSec` / `ttsEnabled`），设置卡与右键菜单同份读写。

### 交互速查（一目标一行为）

| 点击 / 操作目标 | 唯一行为 |
|---|---|
| 宠物本体（单击） | 挥手动画（现有） |
| 状态卡（单击） | 智能跳转：有待审批 → 审批锚点；否则 → 会话 + 已读 |
| 📖 总结限时入口 | 展开小黑板，入口随即消失 |
| 黑板 ✕ / 黑板外部空白 | 关闭黑板（两者等价） |
| 迷你条 | 不可点（纯只读） |
| 右键菜单新子项 | 今日用量 → 手动开迷你条；查看最近总结 → 展开黑板；会话一览项 → 智能跳转 |
| 悬停 ≈0.5s | 浮现迷你条（纯读取，移开即消失） |
| 拖拽 | 纯物理动画，不承载命令（期间迷你条隐藏、悬停检测挂起） |
| 滚轮 | 宠物本体与迷你条**不劫持**、穿透回页面；黑板 / 菜单内部正常滚动 |
| ESC | 一次关一层最上层浮层（手动迷你条 → 黑板 → 菜单） |

## 环境要求

- DeepSeek Harness（DSH）Web profile（`dsh web`）。
- 素材已随包自带，无需额外下载。

## 安装（一键）

```sh
dsh plugin --profile web add github:jarvislee90s-dot/dsh-foxbell-pet
```

然后**重启 `dsh web`** 并**硬刷新浏览器**（Cmd/Ctrl+Shift+R）。右下角即出现桌宠，设置旁有 🦊 开关。

> 桌宠运行时从插件包自带目录 `assets/` 读取精灵图/语音，无需手动放置。

## 使用

| 交互 | 效果 |
|---|---|
| 拖动 | 任意移动桌宠 |
| 拖拽后松手 | 重力坠落 / 水平抛掷惯性 / 落地压扁回弹 + 补跳（可关「落地物理」） |
| 右键桌宠 | 打开菜单（声音/语音字幕/落地物理开关，双击/黄灯/红灯/蓝灯四场景动作绑定，隐藏、关于） |
| 单击形象 | 固定挥手（不出声） |
| 双击形象 | 随机说一句 + 「双击动作」（默认挥手；字幕=语音文件名，与播放对齐） |
| 点项目卡片 | 切换会话 + 标记已读（不出声） |
| 🦊 按钮（侧栏底部） | 显示 / 隐藏桌宠 |

状态灯：**绿** 运行 · **黄** 待批准 · **红** 报错/断联 · **蓝** 完成未读。done 与 error 卡片在打开对应会话后消失；状态再次出现会重新亮起。

## 语音分组

`assets/voice/` 按状态分 4 个子文件夹，文件名即字幕文字：

| 文件夹 | 触发时机 | 说明 |
|---|---|---|
| `general/` | 双击形象 | 闲聊（随机、组内不连续重复） |
| `approval/` | 出现待批准（黄灯） | 撒娇催促，10s 限频防刷屏 |
| `error/` | 任务报错（红灯） | 委屈/傲娇台词 |
| `done/` | 任务完成（蓝灯） | 求夸/元气台词 |

运行（绿）不播语音。空组静默跳过、不报错。

> ⚠️ 黄灯仅在审批策略为 `ask` 且确有等待批准的请求时出现；`never` 策略下审批自动拒绝，不会挂黄灯（符合语义）。

## 自定义

- **换语音**：把 `.m4a` 放进已装包的 `assets/voice/<组>/`（组名见上表），文件名就是字幕文字；重装/重启后生效。
- **本机开发安装**：用 `dsh plugin --profile web add` 装的是指向本仓库的 symlink（`~/.dsh/profiles/web/node_modules/dsh-foxbell-pet`），改完 `assets/` 或 `lib/` 后**重启 `dsh web`** 并硬刷新浏览器即生效，无需重装。
- **换形象**：替换 `assets/spritesheet.webp`（Codex V2 图集规格：8 列 × 11 行，每帧 192×208，行 0–8 为动画）。见 [docs/SPRITESHEET-CONTRACT.md](docs/SPRITESHEET-CONTRACT.md)。
- **改样式/截断**：改 `lib/client.js` 的 CSS、`lib/index.js` 里的 `truncate(…, 24)`，然后 `npm run build` 并重启。
