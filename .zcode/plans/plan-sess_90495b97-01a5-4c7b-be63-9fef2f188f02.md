# 黑板「含子代理」标注 + 设置卡套原生卡片壳

## 背景调查结论（已查实 harness 源码）

原生设置卡（AgentLoop/Bash/WebSearch 卡）的「一级标题 + 默认收起 + 点击展开 + 保存成功自动收起」来自宿主包内共享的 `PluginCard` 壳组件（`packages/client/ui-settings-plugins/src/client/PluginCard.tsx`）：卡片头是自带按钮、折叠为卡片本地 state、头部可标未保存、保存结算后 `setOpen(false)` 自动收起——**全部是插件卡侧可自绘的 UI，无需宿主 API**。我们此前裸渲染控件所以没有壳。修正此前结论：只要自持壳，「保存后自动收起」完全做得到（之前说不可能是因为以为要控制宿主的卡头）。
