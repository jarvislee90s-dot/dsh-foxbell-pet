# v1.4.0 分支纳入 v2.0.0 FR-2/FR-3 最小兼容子集 + PR 范围声明

## 背景与已验证事实

用户源码宿主 = master（d347e70，0.1.3-alpha.1）。v1.4.0 插件在其上无法挂载，断点已实测确认：pnpm 把插件依赖 `@deepseek-ai/dsh-settings ^0.1.0-rc.7` 解析到注册表 0.1.5-rc.1，而该包从 0.1.0-rc.8 起已无 `installSettingsSection`/`settingsNamespace` 导出（0.1.2-rc.1 tarball 实测 grep 为空；master 源码同样没有）→ host 半模块加载即抛错，宠物整体不出现。

master 侧新 API 已核实（均为只读验证）：
- `ctx.get('settings')`（服务名 `super(ctx, 'settings')`，in-tree 5 处同款用法）
- `settings.installSection(ctx, ns, schema, entry, hooks)`，schema 类型 **仍是 schemastery**（`import type z from '@deepseek-ai/schemastery'`）——现有 `Config` 原样可用
- hooks `{ setSource(current: () => T), onChange(), validate? }`；attach 时回调 scope getter、**detach 时自动回退 `() => entry` 并再调 onChange**——恰好覆盖 review 修复 #3 的 live 配置语义
- ns 校验规则 = 小写连字符标识符，`'foxbell-pet'` 合法；客户端 `settingsScope.bind({ namespace: 'foxbell-pet' })` 一直用裸字符串且 rc.7 上配对成功 → 旧 helper 返回值即 `'foxbell-pet'`（执行第一步仍会 npm pack 0.1.0-rc.7 复核，若非恒等则同步取等价值）
- 平台种子表：`@deepseek-ai/dsh-client-ui-slots` 是合法种子；`dsh-client-runtime` 不存在（死项）；客户端运行时对未知 inject id **静默跳过**（system.ts arriveGraphRow），故 locale/api-gateway 两项留着无害

## 改动清单（3 个 commit，全部在 feature/efficiency-dashboard-p1）

### Commit A — `fix(compat): 设置注册迁移 ctx.settings.installSection（v2.0.0 FR-2 最小子集）`

**`src/index.js`**：
1. 删除第 8 行 `import { installSettingsSection, settingsNamespace } from '@deepseek-ai/dsh-settings'`
2. `export const FOXBELL_PET_NS = settingsNamespace('foxbell-pet')` → `export const FOXBELL_PET_NS = 'foxbell-pet'`
3. apply() 开头的注册块（含 review 修复 #3 的 configSource）整体替换为：

```js
  let configSource = () => entry // installSection attach 时换成 scope live getter，detach 时服务侧自动回退 entry
  const settings = ctx.get('settings')
  if (settings !== undefined && typeof settings.installSection === 'function') {
    settings.installSection(ctx, FOXBELL_PET_NS, Config, entry, {
      setSource: (current) => { if (typeof current === 'function') configSource = current },
      onChange: () => {},
    })
  } else {
    console.log('[foxbell-pet] settings service unavailable — settings card skipped, pet keeps running')
  }
```

（host `inject` 五项**不动**、不加 `'settings'`——防御式获取，老宿主照常启动只是无设置卡。）

**`package.json`**：`dependencies` 移除 `@deepseek-ai/dsh-settings`（迁移后零 import，彻底消灭版本解析风险；`@deepseek-ai/schemastery` 保留）。

**`scripts/validate.mjs`**：两处旧标记检查（`settingsNamespace('foxbell-pet')`、`installSettingsSection`）改为新标记——src/index.js 须含 `settings.installSection`；host `FOXBELL_PET_NS = 'foxbell-pet'` 与 client `namespace: 'foxbell-pet'` 两侧字面量配对检查。

**`package.json`** 的 `dsh.client.inject`：移除 `'@deepseek-ai/dsh-client-runtime'`，保留其余三项（ui-slots 为真实种子边；locale/api-gateway 未知 id 客户端静默跳过无害，全量重列留给 v2.0.0）。
