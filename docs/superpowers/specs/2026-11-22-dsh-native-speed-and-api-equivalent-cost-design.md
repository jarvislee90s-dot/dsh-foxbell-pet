# Foxbell：Token 用量、API 等效费用与 DSH 输出速度

- 日期：2026-11-22
- 状态：按用户修订范围更新，待审阅；未实施
- 对照基线：Foxbell `release@09ab288`（v2.4.0）、DSH `master@2e39e704`／`dsh-v0.2.2-rc.5@9c2670d3`、Tuvis `main@707a11a5`（v0.6.6）

## 1. 目标与范围

Foxbell 仍是 **DSH 内的宠物和统计插件**。从现有入口打开同一个主列看板，顶部切换 **「Token 用量」和「输出速度」**。卡片层级、筛选方式、价格明细、分时价配置、速度图和导出操作以 Tuvis 当前设计与实现为参考；导航和生命周期遵循 DSH，不另开独立应用窗口。**数据源只有 DSH，统计维度可以跨供应商、按模型比较**：一个供应商是 DSH 请求的归属，不是新增采集器。

| 处理 | 功能 |
|---|---|
| 保留 | 宠物状态卡、会话跳转、语音、设置、小黑板；既有 Token 统计、文本与分享图导出、本地每日 Token 阈值和 80%／100% 提醒。 |
| 补齐 | 用量按实际供应商／模型分组和筛选；对齐 DSH 四桶、重试、子代理、已收尾会话和 fork 的归属；增加 API 等效费用、手动固定价与分时价、独立费用 CSV。 |
| 新增 | 看板内的「输出速度」页签，支持近期历史趋势与供应商／模型比较；迷你条保留当前会话原生速度。 |
| 明确排除 | 真实账单、真实订阅额度或余额；引入其他应用的用量采集；分词器估算、独立计时或伪实时速度；在 DSH 原生流式指标之外另造一套含等待吞吐。 |
| 宿主适配或另列待决 | 独立置顶窗口、Tuvis 的多工具采集管理在 DSH 插件内不照搬。自定义渠道别名与订阅渠道绑定、全功能记录中心、新摘要不视为已取消需求，也不是本版验收前置；本版按可证明的 DSH 路由展示和估价。 |

API 等效费用是 **按公开参考价或用户配置单价估算的金额**，不是实际支付或可用额度。原有 Token 告警与费用无关。

## 2. 两个页签的布局与行为

### 2.1 Token 用量

沿用 Foxbell 的宠物右键、迷你条和小黑板入口；打开看板默认进「Token 用量」。参考 Tuvis，把时间范围和导出放在页头，依次展示：**Token 总览 → 用量趋势 → 用量分布 → API 等效费用 → 工作活动**。总览和趋势常开，分布与费用默认展开可折叠，工作活动默认折叠；切换页签再返回保留本次打开看板的视图状态。

- 时间默认沿用现有看板；保留近 5 小时、近 7 天、近 30 天和自定义（最多 31 天），补 Tuvis 的「今天」。日期范围链接本页所有卡片；趋势卡的「全部／按供应商／按模型」只是局部筛选，不改变全局总览、费用行或导出。不添加没有区分度的「工具 = DSH」开关。
- 分布默认按供应商，也可按模型看；模型行保留完整 `供应商 / 模型`，同名模型跨供应商不串账。缺失的来源归「未知」，不根据当前设置或裸模型名猜测。工作活动继续显示会话／工具类指标，不把它们按模型比例拆分。
- 费用卡默认按供应商分组、也可按模型平铺。参考 Tuvis 的五列：供应商／模型、估价、总 Token、缓存命中率、计费详情。首屏显示前 5 项并可展开全部；展开行看分桶用量、实际应用的参考价或手动价、来源和覆盖率。没有跨供应商总金额或渠道小计，避免被识别成真实账单。
- 现有复制文本和分享图片继续导出所选日期的 Token 数据，保留原格式、不插入金额。另增费用 CSV（§4.4）。

### 2.2 输出速度

页头独立切换 **15 分钟／1 小时／5 小时（默认）／24 小时**；桶宽对应 **1 分钟／5 分钟／10 分钟／1 小时**。时间选择与用量页互不联动；切换速度组合不触发费用重算。

- 参考 Tuvis：宽屏左侧为可筛选、排序的供应商／模型组合列表，右侧是单张速度图及指标，窄屏组合列表移到详情下方、指标改为 2×2。组合可按名称、速度或有样本的会话数排序；不把不同供应商、模型或不可比计时数据混成一个总速度。
- 指标默认显示该组合的区间汇总：流式 TPS、平均首 Token 等待（TTFT）、有可靠边界的累计模型用时、可可靠归属的工具用时；工具用时无法归到当前组合时显示 `—`，不拿全会话工具时间冒充。指标各自有样本数。首 Token 等待和模型用时是辅助指标，不是第二种速度口径。
- 图表按完成时间分桶，使用实际范围裁剪边缘部分桶。悬停和键盘聚焦显示桶起止、样本数及对应指标；点击固定，Esc、切换范围或组合清除固定。无样本桶无数值：实测线断开，可用灰色虚线提示视觉连接，但虚线不代表样本或可读数。分别说明「此范围无记录」「历史未读完」「宿主缺少数据」，不画零线代替。
- 迷你条显示「本会话输出速度」，跟随 DSH 当前打开的会话；切会话先清旧值。速度页可同时展示独立标明的当前会话读数，但它不参与历史组合曲线或覆盖范围选择。保留 DSH 主题、可见焦点和键盘操作，不照搬 Tuvis 窗口框架。

## 3. DSH 数据来源与测速方法

| 边界 | 来源 → 输出 |
|---|---|
| 当前会话速度 | 公开 `sessionProjections.snapshot(session, keys)` → `sessionStats.decodeTokens/decodeMs` → 同一会话的累计 `tok/s`。 |
| 历史速度 | 同一批宿主会话事件 → 按原生时序复原可靠的结算样本 → 按时间与 `provider/model` 聚合。 |
| Token 与计价 | DSH 使用事件及官方会话查询 → 按日期／实际路由聚合 Token 与计价时间片 → 看板、估价及导出。 |

### 3.1 当前会话与历史测速

- **口径跟随 DSH。** DSH 自带 `tok/s = 1000 × decodeTokens ÷ decodeMs`。公开投影只给累计值，没有逐请求或时间桶 API。历史按 DSH 的 `step/start`、`assistant/attempt`／`assistant/message` 和公开 `assistantStreamFirstTokenTime` 复用首 Token 规则，使用**同一调用**的首 Token 到消息结算时间及供应商上报输出 Token。不改 DSH，不按日志写入延迟、整轮时长或后续工具耗时计速，也不自行采样、计时、分词。只在宿主结算后更新，不承诺生成中逐字显示。
- 历史速度仅接收能确认成功结算、身份一致、时间次序有效、输出 Token 和生成时长均为有限正值的样本。重试须能归到最后一次成功调用；有明确重试但无法恢复成功边界时，不跨尝试拼首 Token 与用量。取消、未闭合、无流数据、重复和 fork 继承记录不出速度数值。失败重试如有官方可计费用量，仍可进入 Token 账；这和速度样本准入是两件事。
- 用会话 ID 与原生事件身份去重；完成时间落在 `(from, to]`。每组合、每桶按 `1000 × Σ输出 Token ÷ Σ生成毫秒` 加权算速度，不平均单条 TPS；TTFT 只对可可靠对齐的本调用 `step/start → 首 Token` 独立求均值。不宣称经严格准入的历史子集与原生会话全量投影相等。
- 历史以 DSH 会话记录为唯一持久数据源，复用现有 `sessionQuery` 与冷读预算，不增建独立速度账本或直接扫描 DSH 私有日志。进程内只缓存最近 24 小时的数值事实或查询聚合；共享用量既有的宿主读取，不随 UI 轮询反复重读冷会话。部署未组合公开事件／查询能力、历史未完整读出或前缀不完整时，明确显示对应降级；无正值样本不报 `0 tok/s`。

### 3.2 Token 统计与计价输入

- 继续以 Foxbell 范围看板为日期统计来源。用 DSH 官方 `TokenUsage` 对账四桶：未缓存输入（投影 `uncachedInputTokens` 对应事件 `inputTokens`）、输出、缓存读、缓存写。保留既有五项展现和缓存命中率分母；不把「用户输入(估)」或上下文压力算入计费 Token。未观测的桶与真实零分开。
- 以当次 `message.source.provider/model` 为归属，同一尝试最终用量替换临时用量，重试只记独立官方样本，父／子代理及普通 fork 去继承前缀。旧宿主只能看部分会话、冷会话仍在加载或范围外记录不可得时说明覆盖边界，不宣称全量。
- 为分时价保留同一路由四桶及其可证的结算时间（或无歧义的计价时间桶），不把整日用量在各时段按比例分摊。和趋势、统计及导出共用已去重的用量事实；不复制会话正文到价格或速度缓存。

## 4. API 等效费用与费用 CSV

### 4.1 参考价、覆盖率和币种

- 费用按日期区间内实际 `(provider, model)` 的可信四桶，以 `Token × 每百万 Token 单价 ÷ 1,000,000` 分项计算；缓存读和写不得重复并入普通输入。不把 Tuvis 某些旧版 DSH 日档只能计算输出的限制套到完整四桶；只有输出可核实时只报输出估价。
- 每行保留实际路由和用于计价的目录键，支持公开目录能明确匹配的身份。渠道未知、匹配冲突或缺价时不猜价；金额为 `—`，部分计价明确写「仅覆盖已计价部分」，可比较时给出已计价／未计价 Token 和覆盖率。缺价不是免费；只有已确定单价为零才显示 `0`。参考价快照不是历史账单，不声称复原当日价格。
- USD／CNY 可切换，CNY 优先用原生人民币价；没有原币单价而有可用汇率时允许换算，注明换算与日期。汇率不可用时不编造另一币种金额。费用端与 Token 统计端的失败互相隔离。

### 4.2 手动固定价与分时价

- 费用卡「管理计价」打开同一个配置入口；行明细内可直接为模型打开规则表单。对照 Tuvis 支持**固定价／分时价**、USD／CNY，以及未缓存输入、缓存读、缓存写、输出四个每百万 Token 单价。规则以可证归一化模型标识匹配，可明确限定原始供应商；不限定时即用户主动选择对该归一化模型全局应用，不改变路由分组。显示别名不参与匹配。
- 手动价优先于公开目录；明确限定路由的规则优先于全局模型规则。同级冲突不自动猜测；字段留空回退到能确定的目录价，目录无价则该桶不估。至少一项价格须有效，非负、最多 9 位小数；允许明确输入零。目录刷新不覆盖已保存的用户规则，保存失败保留草稿。
- 分时对齐 Tuvis：选择**宿主本地／上海／UTC**，用周一至周五的多段高峰整点范围 `[起点, 终点)`，其余时段为低谷。跨午夜时按**起始日**判断工作日，例如周五晚开始的窗口可延续至周六凌晨；拒绝重叠、零长度或非法时段，不推断法定节假日。低谷某项留空回退有效目录价。保存前展示时区、单价和适用对象；行内同时注明价格规则和加权参考单价。
- 只有日聚合、无法恢复时段但用量可靠时，沿用 Tuvis 的低谷价回退并标注「时段不可辨，按低谷价估算」；低谷／目录也不可用就标未估价。没有可证结算时间的记录不得被归到任何高峰窗口。

### 4.3 价格与汇率同步

首次打开费用区且无快照时自动同步；费用区再次使用时发现快照超过 24 小时则后台刷新，并提供手动同步。同类并发请求合并，查询先读本地，不阻塞 Token 与速度视图。参考 Tuvis 的 `models.dev` 公共价目录、原生人民币数据与 USD/CNY 汇率源，仅向公开白名单地址取价，不发送会话、路径、凭据、路由清单和 Token 数。

验证成功后保存最后有效的价格／汇率快照与来源时间；失败沿用仍可读取的旧快照并标注日期和同步状态，无快照且没有手动价时不报金额。汇率故障不影响同币种估价或其他可用价格。

### 4.4 费用 CSV

- 用量页导出条新增「费用 CSV」，与复制文本和导出图片并列。导出当前日期范围的**所有估价结果行**（包括部分及未估价），与费用卡共用查询与同次价格快照；不受趋势局部筛选、折叠、Top 5 或费用显示币种影响。固定 USD，无跨渠道总计行；只有人民币价而无可用汇率的金额留空并标出 USD 状态。
- UTF‑8 CSV，标准字段转义，防止供应商／模型等文本字段被表格软件解释为公式。Foxbell 字段序列：`source_id`（固定 `dsh`）、`observed_provider`、`model_id`、`normalized_model_id`、`token_usage`、`estimated_usd`、`status`、`priced_tokens`、`unpriced_tokens`、`coverage_rate`（0–1，未知留空）、`pricing_provider`、`pricing_model`、`pricing_snapshot_id`、`price_updated_at`、`pricing_basis`、`price_rule_kind`、`time_price_daily_fallback`、`range_from`、`range_to`。不编造 Tuvis 多工具或计费渠道 ID。导出仅下载，不联网、不写回用量数据，不改变现有文本与图片导出。

## 5. DSH 兼容边界

- **完整目标：** `dsh-v0.2.2-rc.5` 的 Web profile 与官方桌面端；以发布标签作验收，master 作前向源码参考。沿用 `shell.overlay`、`settings.section` 和主列看板入口，不依赖 DSH 私有 UI、已退役 slot 或实验统计插件。
- **旧版保底：** 保留 `0.1.2-rc.1` Web 与 `0.2.0-rc.2` 桌面原功能。新增能力按公开服务和实有字段开启；缺速度投影且能读可靠结算事件时只显示历史区间，反之只显示可得的会话累计；两者均缺时给不可用提示。不因新统计提高硬注入要求。没有 Web／slots 的 profile 不挂载宠物或看板。

## 6. 验收矩阵

| 场景 | 通过条件 |
|---|---|
| 新版 Web／桌面安装及看板导航 | 两页签在同一主列；各自范围和选中状态不串；原宠物、黑板、配置、阈值和导出可达；卸载释放监听和刷新任务。 |
| 当前会话切换 | 迷你条同 DSH 当前会话累计速度一致，旧读数立即撤下；缺数据不填零；日期范围不影响当前会话累计读数。 |
| 历史测速 | 四档范围和桶宽正确；两条不同时长的记录验证加权 TPS；桶边界及重复样本不双计；不可靠重试、失败和缺首 Token 的样本不进入速度；无样本不插值。 |
| 速度页宽窄布局与交互 | 组合筛选、排序、图表悬停／键盘、固定和空态可用；工具用时无法归属时显示 `—`；呈现不含分词器或含等待吞吐切换。 |
| 用量归属 | 两供应商用同名模型仍分行；无归属不猜；局部趋势筛选不改总览或导出；重试与子代理按宿主事实对账，普通 fork 不重复计。 |
| 固定价、分时价和覆盖率 | 手动价优先，缺项回退；核对周五跨周六、周六跨周日、多个时区与边界整点；拒绝重叠和非法价；日档低谷回退明确标识；无价留空，现金金额不重复计缓存。 |
| 价格同步和 CSV | 自动／手动、缓存过期、断网及无汇率状态都可验证；相同快照的 USD CSV 与费用行一致，不受显示币种或趋势筛选影响，部分缺价行仍导出，现有导出无新增金额。 |
| 旧版和无界面 profile | 原有交互与统计不退化，仅降级缺数据的新指标；无界面 profile 不挂载。 |

验证采用固定 DSH 事件和价目样本的单元测试、宿主能力缺席的适配测试，以及上述版本矩阵的安装和 UI 冒烟。此处只完成源码和版本对照，未执行实现验收。
