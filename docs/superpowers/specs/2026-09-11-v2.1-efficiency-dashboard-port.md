## 5. 行为不变量（验收基准，逐条可测）

1. 五口径语义与文案：请求输入=uncached+cacheRead 逐请求累加（同 (turn,step) 替换、`llm/retry-started` 累加）；命中率=cacheRead/请求输入（分母 0 记 0）；你的输入=启发式估算带「(估)」；黑板含「· 含子代理」尾注。
2. 警报跨阈值判定 + 日键 id（`day-warn:<date>`），同档仅一次；里程碑整数关口一次性。
3. 档位刻度默认值（高强度 12 事件/5min、长跑 3min、摸鱼 15/25/35/60min）与全部 12 配置默认值不变。
4. 交互规则（spec 6.6 全集）：单击每目标单行为、悬停纯读取、拖拽无命令、ESC 分层、滚轮穿透、右键仅本体、黑板优先互让。
5. 纯 token 口径、零金额、白名单（不显示 prompt 原文/代码/密钥）。
6. 宿主 dsh ≥ 0.1.2-rc.1 基线（snapshotEvents-only，继承 v2.0.0）。
